## Findings
1. **Incomplete migration mapping.** firebase.json has no legacy redirects. Confirm the exact old URLs in Google results or Search Console. Map each to a genuinely relevant replacement using permanent redirects; retain a 404 where no replacement exists. Do not redirect every removed page to the homepage.
2. **Minimal initial HTML.** scripts/generate-seo.mjs emits only a heading, one description paragraph and links to Home/Chemicals for each route. Product descriptions, application details, navigation and catalogue links depend on JavaScript rendering. This is not evidence that Google cannot render the pages, but full prerendering would make content and discovery more robust.
3. **Metadata does not follow client navigation.** SEO tags are generated in HTML at build time; the React router changes pages without a metadata update mechanism. Direct requests have correct metadata, but navigation can leave the previous page's title/canonical/JSON-LD in place. Correct this alongside prerendering.
4. **Private routes receive homepage SEO HTML.** /signin is rewritten to index.html and serves index/follow with the homepage canonical. robots.txt blocks crawling, but blocks alone do not guarantee that a URL cannot be indexed. Give private routes noindex metadata/headers and consider allowing crawling if removal from indexing is needed, while retaining authentication.
5. **Sitemap has no lastmod.** Optional, not a crawl blocker. If added, use actual substantive modification dates rather than the current date on every build.

## Authorized remediation

- Render the complete public React pages into the build HTML, including catalogue links, product details and navigation.
- Share metadata between the static build and client navigation. Separate Product entities from WebPage entities in JSON-LD.
- Serve independent noindex shells and X-Robots-Tag headers for private pages; allow crawlers to read the directives.
- Restore legacy URLs with 31 explicit permanent redirects. Archived records confirmed the historical `.php` routes, including technology.php, production-completion.php and fracturing-stimulation.php. Technology points to About Us, chemical categories to Chemicals, and matching historical products to their current detail pages. Unrelated retired equipment/products retain 404s.
- Trigger the existing production Hosting workflow for build-script changes and require SEO output checks before deployment.
