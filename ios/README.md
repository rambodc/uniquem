# Uniquem iOS app

A native iPhone app (Capacitor 8, Swift Package Manager) that ships the website build from `dist/` inside the app. It never loads a
remote URL. It opens on `/dashboard` (sign-in when signed out). Bundle id `ca.uniquem.app`, team `3CW838WDQC`, iPhone only.

## Build locally (Mac with Xcode 26)
```
npm ci
npm run ios:sync      # builds the website and copies it into ios/App/App/public
npm run ios:open      # opens Xcode; pick a device and Run
```
`ios/App/App/public` and `ios/App/CapApp-SPM/symlinks` are generated by `cap sync` and are not committed.

## TestFlight
GitHub → Actions → **iOS - TestFlight** → Run workflow (manual only). It builds on `macos-26`, signs Release with the
"Apple Distribution: Rambod Rad" certificate and the "Uniquem App Store" profile (manual signing, no registered devices needed;
secrets `IOS_DIST_P12`, `IOS_DIST_P12_PASSWORD`, `IOS_APPSTORE_PROFILE`) and uploads with the App Store Connect API key
(`ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8`). Release uses `App.Release.entitlements` (push `production`); Debug stays automatic
with `App.entitlements`. The build number is the workflow run number. Cert and profile expire Oct 31, 2027.

## Firebase
- iOS app `1:1023614587151:ios:2dd238480732363b1eee7a` in project `uniquem-4366e`; its config is `ios/App/App/GoogleService-Info.plist` (not secret).
- Sign-in, callables and Storage use the same Firebase web SDK as the website, inside the app's web view.
- **App Check**: the website uses reCAPTCHA Enterprise, which can't run in the app. In the app (`src/native/appCheck.ts`) the native
  Firebase SDK attests with **App Attest** and hands the token to the web SDK, so every callable keeps passing App Check enforcement.
  App Attest works on real devices (TestFlight and App Store builds). On a simulator, build with `VITE_APPCHECK_DEBUG=true npm run ios:sync`,
  run once, copy the debug token printed in the Xcode console and add it under App Check → Apps → Uniquem (iOS) → Manage debug tokens.
  Never ship a build with `VITE_APPCHECK_DEBUG=true`.
- **Push**: `@capacitor-firebase/messaging`. After sign-in the app asks for notification permission and registers with FCM.
  A notification with `data.path` (for example `/party/abc123`) opens that page when tapped. APNs needs the APNs auth key uploaded
  to Firebase (Project settings → Cloud Messaging → Apple app configuration).
